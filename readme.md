# Pull-Req 🚀

Just a chill, open playground for practicing Git workflows, testing branches, and getting comfortable with making pull requests!

Whether you're testing out a new Git alias, trying to figure out how merge conflicts actually work, or just want to make your very first open-source PR without the pressure of breaking production code, feel free to drop changes here.

---

### 🛠️ What's in here?
- Simple frontend markup & styles (`index.html`, `style.css`, `script.js`)
- Test notes & random updates (`msg.txt`)

---
